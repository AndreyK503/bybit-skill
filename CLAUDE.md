# bybit-skill

CLI + скилл только на чтение для аккаунта Bybit. Требования: @spec.md. План: @plan.md.

## Команды проверки

```
npx vitest run
npx tsc --noEmit
npx eslint .
npm run build
```

## Правила работы

- Задача не завершена, пока все четыре команды проверки не зелёные.
- Всегда показывай вывод команд. Не пиши «готово» без вывода.
- Тесты не редактировать, чтобы они прошли — чинить реализацию.
- Если проверка невозможна — скажи об этом, не имитируй успех.
- Не подавляй ошибку и не помечай тест skip/todo — чини причину.
- Источник требований: @spec.md и @plan.md.

## Жёсткие ограничения

- Транспорт умеет только GET. Функции, отправляющей POST/PUT/DELETE/PATCH или тело
  запроса, в коде не существует (D-1, критерий приёмки 20). Стережёт
  `src/readonly-guard.test.ts`.
- Ключ и секрет никогда не попадают в вывод, логи и сообщения об ошибках (D-10).
- Расчётные значения отделены от сырых (`computed` + `computedNotes`, D-9). Если
  корректный расчёт невозможен — пустое значение с причиной, не приближение (NFR-3).
- Бандл — CommonJS под Node 20: в `src/` нет top-level await.
