# bybit-skill — скилл и CLI для счёта Bybit, только на чтение

Скилл для ИИ-агента (Claude Code и другие агенты со скиллами), который отвечает
на вопросы о вашем счёте Bybit по реальным данным: портфель, остатки, позиции,
опционы с греками и маржой, доска опционов, сделки, результат за период,
сколько заработано за всё время, котировки и свечи.

Спрашиваете обычным языком — «какие у меня опционы и какой по ним риск?»,
«сколько я заработал за месяц?», «покажи доску BTC» — агент вызывает встроенный
CLI, получает свежие данные с биржи и отвечает по ним, а не по памяти.

Скилл не торгует и не может торговать. Подробнее — в разделе «Безопасность».

## Что умеет

**Счёт.** Общая стоимость счёта и из чего она складывается. Остатки по монетам
отдельно по торговому счёту, кошельку финансирования и Earn. Открытые позиции,
использование маржи, нереализованный и реализованный результат.

**Опционы — главное.**
- Позиции с разбором контракта: монета, страйк, экспирация, тип, дни до
  экспирации, четыре грека.
- Нетто-греки портфеля по базовой монете; дельта только по опционам.
- Маржа Portfolio Margin по монетам: худший сценарий цены и IV и сколько в нём
  теряет каждый опцион.
- Доска по монете: без даты — ближайшая месячная экспирация; фильтры по типу и
  страйкам.
- Список дат экспирации, месячные отмечены.

**История (до 2 лет — это предел биржи).** Сделки с комиссиями, а по опционам —
с IV сделки и ценой базового актива. Журнал операций с итогами по типам.
Реализованный результат за период, включая исполнения на экспирации. Скилл сам
собирает длинный период кусками и честно называет границу, если биржа глубже
данных не отдаёт.

**Сколько заработано за всё время.** Все вводы и выводы с первой операции
счёта, включая P2P и переводы с субсчётом, в долларах на дату операции.
Нетто-ввод, текущая стоимость, разница между ними и срок.

**Рынок.** Котировка, свечи (день, неделя, месяц) до 3 лет, стакан, карточка
инструмента, поиск по тикеру.

## Безопасность

Только чтение гарантировано дважды:

1. **Ключ.** Скилл работает только с ключом API «Read-Only». Ключ с правами на
   торговлю или вывод CLI отвергает при каждом запросе к счёту.
2. **Код.** В CLI нет функции, которая может отправить изменяющий запрос: он
   умеет только GET. Это проверяет отдельный тест по исходникам и по собранному
   файлу.

На просьбу совершить сделку, перевод или вывод агент отказывает и объясняет
почему.

Ключ и секрет лежат в `~/.config/bybit/.env`, вне каталога скилла и
репозитория. В вывод, логи и сообщения об ошибках они не попадают. Агенту
запрещено читать этот файл.

## Установка

Нужен только Node.js 20 или новее. Пакеты ставить и собирать ничего не нужно.

```bash
curl -fsSL https://raw.githubusercontent.com/AndreyK503/bybit-skill/main/install.sh | bash
```

Установщик (Linux, macOS, WSL):
- кладёт скилл в `~/.claude/skills/bybit` и `~/.agents/skills/bybit`;
- создаёт `~/.config/bybit/.env` с пустыми строками ключа и правами 600;
- уже существующий `.env` не трогает.

Повторный запуск обновляет скилл, ключ остаётся на месте.

Установка из локального пакета, без скачивания:

```bash
BYBIT_SKILL_FILE=./bybit.skill bash install.sh
```

Вручную: распакуйте `bybit.skill` (это ZIP) в каталог скиллов агента:
`unzip bybit.skill -d ~/.claude/skills`.

## Ключ API

1. На сайте Bybit откройте управление API и создайте системный ключ с доступом
   **Read-Only**. Отметьте на чтение все разделы данных, иначе часть команд
   ответит «нет прав». Привязка к IP — по желанию.
2. Впишите ключ и секрет в `~/.config/bybit/.env`:

   ```
   BYBIT_API_KEY=ваш_ключ
   BYBIT_API_SECRET=ваш_секрет
   ```

   Без кавычек и пробелов. В чат ключ не отправляйте.
3. Перезапустите сессию агента и спросите: «скилл видит мой счёт?». Агент
   выполнит `session status`: он показывает маскированный ключ, права, режим
   счёта, связь с биржей и расхождение часов.

Счёт должен быть единым торговым (UTA): опционы на Bybit есть только в нём.

## Сеть

Некоторые провайдеры блокируют `api.bybit.com`, подменяя DNS. Тогда CLI
отвечает «Биржа недоступна (нет соединения)» или «ответ в неожиданном формате»
(`APP_UNAVAILABLE`). Повтор не поможет: включите VPN или смените DNS на
`1.1.1.1`.

Bybit не обслуживает США и материковый Китай (`APP_REGION_BLOCKED`).

## Команды

Агент вызывает их сам. Руками — так:

```bash
node ~/.claude/skills/bybit/scripts/bybit.cjs <команда> [параметры] [--json]
```

| Группа | Команды |
|---|---|
| Доступ | `session status` |
| Счёт | `portfolio`, `balance`, `positions` |
| Опционы | `opt positions`, `opt greeks`, `opt margin`, `opt expiries`, `opt chain <монета>` |
| История | `trades`, `operations`, `pnl`, `deliveries` — период `--days N` или `--from`/`--to` |
| За всё время | `funds` |
| Рынок | `quote`, `history`, `orderbook`, `instrument`, `search` |

Параметры любой команды — `--help`. Без `--json` вывод — таблицы для человека,
с `--json` — структура для агента.

Длинные выборки идут минуты: `pnl` за 2 года — около 4, `funds` — около 2–3.
Прогресс печатается в stderr.

## Как это работает

- **Один файл.** CLI на TypeScript собран в `skills/bybit/scripts/bybit.cjs`
  без внешних зависимостей. Подпись запросов — HMAC-SHA256 через `node:crypto`.
- **Свежие данные.** Каждый ответ строится на запросах к API Bybit V5 в момент
  вопроса. Кэшируется только справочник тикеров спота и бессрочных — на сутки,
  в `~/.config/bybit/cache/`. Опционы не кэшируются.
- **Сырое отдельно от расчётного.** Значения биржи выводятся как есть. Всё, что
  вычислил скилл, лежит в `computed`, пояснение метода — в `computedNotes`, в
  таблицах помечено `[расчёт]`. Если корректно посчитать нельзя, значение
  пустое и рядом причина, а не приблизительное число.
- **Длинная история** собирается окнами (биржа отдаёт 7 или 30 дней за запрос),
  без потерь и дублей на стыках, с соблюдением лимитов запросов.
- **Ошибки** переводятся в понятную причину и действие с кодом `APP_...`:
  неверный ключ, нет прав, часы ушли, регион, лимит, биржа недоступна.

Что именно расчётное в каждой команде и где ловушки, описано в
`skills/bybit/references/commands.md`. Требования — `spec.md`, технический
план — `plan.md`.

## Разработка

```bash
npm install
npx vitest run
npx tsc --noEmit
npx eslint .
npm run build     # skills/bybit/scripts/bybit.cjs
npm run pack      # сборка и упаковка в bybit.skill (нужен uv)
```

Пакет `bybit.skill` лежит в репозитории: установщик скачивает его отсюда. После
изменений в `skills/bybit/` выполните `npm run pack` и закоммитьте пакет.

## Дисклеймер

вами. Расчётные значения помечены и описаны; при сомнении сверяйтесь с
приложением Bybit.
